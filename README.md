# lucnijs.be

Personal website of Luc Nijs, rebuilt in [Astro](https://astro.build) from the Wix site.

```bash
npm install
npm run dev
```

- `src/pages/` – one file per page, with the same addresses as on Wix
- `src/layouts/Base.astro` – header, menu and footer
- `src/styles/` – `site.css` for the layout, `type.css` for fonts, sizes and colours
- `public/` – images, audio, PDFs and the embedded pages (publications, lectures map, CVs)
